# 로드맵

## 페이즈 개요

| 페이즈 | 목표 | 상태 |
|--------|------|------|
| **1** 세로 슬라이스 | 탭·머지·오프라인·강화·환생이 한 루프로 돈다 | **완료 (코드)** |
| **2** 리텐션 | 다시 켜고 싶게: 유물·미션·콘텐츠 깊이 | 예정 |

페이즈 2–3는 **페이즈 1 루프가 재미있는지** 손플레이로 확인한 뒤에 연다. 처음부터 길드/PvP/라이브옵스를 넣지 않는다.

## 페이즈 2 — 리텐션

우선순위 제안:

1. **유물 8종** — Time Crystal 소모 영구 보너스 (탭/DPS/골드/오프라인 캡)
2. **스테이지 200**까지 페이싱 재튜닝 + 보스 연출(단순)
3. **크리처 라인 3개** (예: 숲 / 바다 / 불) — 머지 트리 분기
4. **일일 미션** 3개 (스테이지 N 클리어, 머지 M회, 오프라인 수령)
5. **오프라인 상한 업그레이드** (8h → 10h → 12h)
6. 도감 보상 (티어 완성 시 젬/크리스탈)

완료 정의: D1/D7을 볼 소프트 빌드 배포 가능, 환생 2회차 루프가 막히지 않음.

## 페이즈 3 — 글로벌 출시

1. AdMob: 보상형(2×/스킵), 전면(세션 간, 빈도 제한)
2. IAP: 젬팩, 광고 제거, 스타터팩
3. Firebase: Analytics / Crashlytics / Remote Config (`balance` 핫픽스)
4. 이벤트: `stage_clear`, `prestige`, `ad_reward`, `iap`
5. l10n: en, es, pt-BR, id, th, vi, ko, ja, zh-Hans, de, fr, ru
6. 스토어: 스크린샷, 설명, 프라이버시 정책, 12+ 레이팅
7. Soft launch 1–2개 국가 → 글로벌
